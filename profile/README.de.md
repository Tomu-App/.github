# Tomu

[English](https://github.com/Tomu-App/.github/blob/main/profile/README.md)

**Geteilte Listen. Ohne Konto.**

Tomu ist eine per Link geteilte Liste für To-dos, Haushaltsaufgaben, Packlisten, Einkaufslisten und mehr. Geteilte Listen für Familie, Mitbewohner und Freunde: Alle sehen Änderungen sofort, und niemand sonst kann mitlesen.

## Was Tomu anders macht

- **Kein Konto.** Du teilst einen Link, das war's.
- **Ende-zu-Ende-verschlüsselt.** Der Schlüssel steckt nur im Link. Der Server speichert ausschließlich Chiffretext und kann deine Listen nicht lesen.
- **Kein Tracking.** Keine Analyse-Tools, keine Tracking-Pixel.
- **Echtzeit-Synchronisation, funktioniert offline.** Änderungen, die du offline machst, werden synchronisiert, sobald die Verbindung zurück ist.
- **Einfach genug für Oma.** Große Schrift, große Schaltflächen, wenige Optionen.
- **Teilen über Labels.** Teile ein Label einmal, und jede Liste mit diesem Label, auch zukünftige, ist geteilt.
